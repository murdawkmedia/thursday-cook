# Thursday

Situational awareness for humans: aviation-inspired workflows that meet people
where they are.

Thursday is a set of ideas

- to help people
- build systems
- to achieve
- their own goals
- safely
- by making tiny changes
- one at a time.

Try the [Idea Expander](https://trythursday.org/experiments/idea-expander) now.

Structure:

- `threads/` - experimental info organization system
- `personal/` - gitignored, dirs that contain people info at the relevant scope
    - `personal/scratch/` - personal scratch (e.g. the concept tree)
- `experiments/` - prototypes and ideas.
- `scratch/` - empty on purpose; a throwaway workspace at the root
