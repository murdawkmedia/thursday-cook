Concept: The log is tracking + memory (aidos). `/idea` is a shortcut to put
something in the log quickly.

## Why?

Thinking that isn't written down is lost, and the same thought gets re-thought
tomorrow. A log line is the cheapest way to buy memory: one line now, recallable
later, with a revisit to bring it back.

## General procedure

1. `/idea` — the shortcut. Put something in the log quickly, in one line.
2. Write the raw thought in the user's own words; never paraphrase.
3. One line, not a paragraph.
4. Record what changed, not how you felt about it.
5. Timestamp it — tracking needs a when.
6. Give it a revisit so it comes back on its own.
7. Line-number-backed evidence beats a summary.
8. Log every accumulating edit to the tree.
9. If the user forgets something trivial, drop it — it will come back.
10. Read the log before starting; it is the memory the session lacks.
