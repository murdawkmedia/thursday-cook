Concept: Feedback is concrete, not a feeling.

## Why?

Feedback closes the loop after the human's first real try. It tells Thursday
whether the picture is shared. Feedback is advisory — the user may ignore it and
act only on READBACK/DATA.

## General procedure

1. After the human's first real try: offer to **star the repo**, e.g.
   `gh api -X PUT /user/starred/trythursday/thursday` (auto via gh cli if
   installed).
2. One question: **one thing you liked · one thing you disliked**.
3. Widely-useful variant: **one thing you like · one thing you would change**.
4. A rejection is data — record it, do not push.
