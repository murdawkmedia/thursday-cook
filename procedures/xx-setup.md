Concept: How to start using Thursday, and how to reach any skill in it.

## Why?

The user should learn everything they need in under a minute. `/thu` reaches the
root skill; `/th-` reaches a specific one. Nothing has to be remembered — the
names mirror the procedures.

## General procedure

1. `/thu` — the root skill. Start here.
2. `/th-` — reach a specific skill, e.g. `/th-lenses`, `/th-refine-idea`.
3. Procedures live at `procedures/xx-<name>.md` at the repo root.
4. Skills are generated into `.agents/skills/th-<name>/SKILL.md` by
   `experiments/gen_th_skills.py`.
5. `/idea` — the shortcut to put something in the log quickly.
6. Goal: `/thu hello` → learn everything you need in under a minute.
7. If the user seems unsure, ask one question — never tell them the answer.
8. Everything is a resource; start with the ones they already have.
